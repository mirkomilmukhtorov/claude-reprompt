# Model-routing framework

1. Parse task type, constraints, modality, required tools and access.
2. Exclude unverified, inactive and unsupported candidates; respect explicit provider/model preference.
3. Favor fast economical models for extraction, summarization and routine transformations; balanced models for well-scoped coding; advanced models for high-uncertainty multi-step engineering and research.
4. Compare latency, budget, quality needs, context and available tools. Unmeasured performance differences are hypotheses, not facts.
5. Select only a supported reasoning value and present conditional access assumptions. Provide best overall, performance, balanced and budget alternatives when informative.
