# Task-specific patterns

Coding: inspect relevant repository first, preserve conventions, list implementation scope, test affected paths, report changed files and unresolved risks.
Read-only audit: prohibit changes, deployments, database writes and cleanup; cite observed evidence.
Deep research: prioritize primary sources, verify dates, compare contradictions and cite claims.
Multi-agent: parallelize independent tracks only, assign ownership and integration checks.
Data analysis: define inputs, calculations, missing-data handling and validation.
UX/design: specify target audience, constraints, artifacts and accessibility checks.
Security and high-stakes: constrain authorization, verification and sensitive data exposure.
