# OpenAI prompt optimization

Use the model's official API identifier, not its marketing UI name. State a concrete objective, authorized scope, relevant inputs, completion criteria and output format. Keep instructions brief for simple tasks. For code agents, require inspected evidence, tests run, and explicit unresolved blockers. Apply reasoning.effort only if the selected model supports that value. Do not ask for hidden chains of thought.

Official sources: https://developers.openai.com/api/docs/guides/prompt-engineering and https://developers.openai.com/api/docs/guides/reasoning
