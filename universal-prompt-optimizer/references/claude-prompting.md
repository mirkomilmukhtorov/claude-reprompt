# Claude prompt optimization

Prefer clear and direct instructions. Use XML or headings to separate large input blocks and outputs where helpful. Provide concrete acceptance criteria and examples when ambiguity warrants them. Define tool permissions, allowed edits, and tests for coding agents. For current 5.x models, distinguish adaptive thinking from output_config.effort and do not assume manually configured thinking budgets.

Official sources: https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices and https://platform.claude.com/docs/en/build-with-claude/effort
